## Contract

For each value in nums1, return the first greater value to its right in nums2, or -1. nums2 has distinct values and contains nums1.

## Approach

A decreasing stack holds unresolved values. A larger arriving value resolves every smaller value at the top.

## Run the example

Use Node.js 24 or newer. Save the following beside `LC-496-next-greater-element-i.js` as `example.mjs`, then run `node example.mjs`. The implementation is displayed below.

```js runnable
import { nextGreaterElement } from './LC-496-next-greater-element-i.js';
console.log(JSON.stringify(nextGreaterElement([4, 1, 2], [1, 3, 4, 2])));
```

```text output
[-1,3,-1]
```

## Cost and edge cases

O(m + n) expected time and O(n) space. Every stack value is pushed and popped once. Repeated values require index-based handling and are outside this contract.
