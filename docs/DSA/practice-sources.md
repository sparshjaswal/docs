# Sources and scope

The practice catalog is organized by LeetCode ID: **487 distinct LeetCode questions**, **329 detailed workbook entries**, and **47 general exercises** across **18 source topics**. Each imported question has one main home in a table-only Practice Problems section. Select a question title to open its statement, examples, and constraints without leaving the lesson. Each concept has one practice table, including its authored and JavaScript workbook questions. The other catalog entries provide direct practice links. Existing repository examples are linked to the same question instead of being copied. Six additional repository questions remain available below.

The source records a catalog snapshot from **13 October 2026**. This import preserves that snapshot; it does not independently verify current difficulty, Premium status, examples, or judge constraints. General exercises have no assigned LeetCode ID, and related examples do not establish an exact match. Empty JavaScript starters are exercises, not completed solutions. Some older repository examples and tests are also unfinished.

Superscript bounds are transcribed as powers (for example, `10^9`). The canonical source data retains workbook headers, original page numbers, source labels, and verification notes. Source SHA-256: `9f9895062f732068b3b18f86c62c67647191fcf221bd8fe3c4c003addad842de`.
