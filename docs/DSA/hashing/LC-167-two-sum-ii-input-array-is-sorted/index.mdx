## Contract

For a sorted numeric array, return one-based indices of two different values whose sum is the target.

## Approach

Compare the two ends. A sum that is too small rules out the current left value; a sum that is too large rules out the current right value.

## Run the example

Use Node.js 24 or newer. Save the following beside `LC-167-two-sum-ii-input-array-is-sorted.js` as `example.mjs`, then run `node example.mjs`. The implementation is displayed below.

```js runnable
import { twoSum } from './LC-167-two-sum-ii-input-array-is-sorted.js';
console.log(JSON.stringify(twoSum([2, 3, 4], 6)));
```

```text output
[1,3]
```

## Cost and edge cases

O(n) time and O(1) extra space. The input remains unchanged. The exercise guarantees a solution; this implementation returns [] if none exists.
