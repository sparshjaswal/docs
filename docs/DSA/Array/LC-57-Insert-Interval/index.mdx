## Contract

Insert a closed interval into sorted, non-overlapping closed intervals and merge any overlaps.

## Approach

Copy intervals entirely before the new one, extend the new interval across overlaps, then append the intervals after it. Touching endpoints overlap.

## Run the example

Use Node.js 24 or newer. Save the following beside `LC-57-Insert-Interval.js` as `example.mjs`, then run `node example.mjs`. The implementation is displayed below.

```js runnable
import { insert } from './LC-57-Insert-Interval.js';
console.log(
  JSON.stringify(
    insert(
      [
        [1, 3],
        [6, 9],
      ],
      [2, 5],
    ),
  ),
);
```

```text output
[[1,5],[6,9]]
```

## Cost and edge cases

O(n) time and O(n) result space. This implementation changes the newInterval pair and shares unchanged interval pairs with the input. Pass copies if that sharing is unwanted.
