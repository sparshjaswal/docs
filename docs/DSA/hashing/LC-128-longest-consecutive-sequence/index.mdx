## Contract

Return the length of the longest run of consecutive integers, regardless of their order in the input.

## Approach

Build a set. Start a run only when its predecessor is absent, and iterate the set so duplicate starting values cannot repeat the same work.

## Run the example

Use Node.js 24 or newer. Save the following beside `LC-128-longest-consecutive-sequence.js` as `example.mjs`, then run `node example.mjs`. The implementation is displayed below.

```js runnable
import { longestConsecutive } from './LC-128-longest-consecutive-sequence.js';
console.log(JSON.stringify(longestConsecutive([100, 4, 200, 1, 3, 2, 1])));
```

```text output
4
```

## Cost and edge cases

O(n) expected time and O(n) space under set-lookup assumptions. Empty input returns 0. Each distinct value belongs to exactly one scanned run.
